[cols="2,5a", options="header"]
|===
| Goal / Requirement | Architectural Approach

| Functional Suitability & Scalability
| Modular monolith with strict module boundaries; stateless, so it
scales horizontally behind a load balancer. Modules are incrementally 
extracted into microservices as concurrent users grow.

| Secure, flexible and event-driven technology stack
|
* Frontend: Flutter - one codebase for Android and iOS.
* Backend: Spring Boot - REST API, holds business logic.
* Data & notifications: Firebase.
* Events / Real-Time: Apache Kafka for internal events, live updates reach apps via Firestore/FCM.
* Maps: Maps API, routing and matching.
* Payments: Stripe.
* Security: TLS, encryption at rest, secrets management, token-based auth.

| Cloud
| Google Cloud Platform, Firebase is native to GCP.

| QA Approach
| Layered tests - unit, integration, end-to-end, security, performance,
user-acceptance - plus Google Cloud Monitoring
|===
